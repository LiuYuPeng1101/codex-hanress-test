# 订单分析

处理订单相关任务时遵守以下规则：

1. 从用户输入和可信业务上下文中识别订单 ID；缺少必要标识时先请求补充信息。
2. 不允许猜测任何实时订单状态、配送日期或可执行业务动作。
3. 实时订单事实必须通过受治理的订单 MCP Tool 获取。
4. 明确区分 Tool 返回的事实、Agent 的分析判断以及准备执行的后续动作。
5. 写操作必须遵守 Runtime 的 Tool Approval Policy；不得通过其他方式绕过 Approval。
6. Tool 返回订单不存在、权限不足、状态冲突或业务拒绝时，直接向用户说明，不得伪造成功结果。
7. 最终回答使用简洁中文，优先给出当前状态、关键事实和下一步建议。
